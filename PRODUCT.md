# Product

## Platform
web
## Users
College assessors reviewing the supplied creative AI portfolio; portfolio visitors exploring finished work and the prompting behind it.
## Product Purpose
Show the actual supplied assets alongside detailed reconstructed generation prompts, with a coherent immersive presentation and direct access to the source works.
## Capabilities and Constraints
Image viewing, native audio/video playback, external Suno song links, article preview, searchable category index, prompt copying, process and critical reflection. Reconstructed prompts must be clearly distinguished from original records. Original prompts and confirmed generation-tool histories are not supplied. Do not invent institutional affiliations or claim the project was assessed by Oxford.
## Brand Commitments
The user explicitly pins the visual design, fonts, color grade and 3D immersion to bryangarage.dev. Preserve that dark technical spatial language while using the user's own content.
## Evidence on Hand
Supplied assignment ZIP with 9 infographics, 2 AI images, 6 podcast recordings, 4 video explainers, 1 Pages newsletter. Screenshot supplies 5 Suno song titles and links. Owner name and course/college wording remain undecided pending user response.
## Stack
Implementation choice: Vite, vanilla JavaScript, Three.js and GSAP for a static deployable portfolio. This is a working implementation choice for the requested site, not a confirmed long-term user preference.

## Confirmed refinement
The user requests a single-page 3D-only default experience matching the spatial archive. Remove the scrolling landing page and grid from the default experience. Preserve the full asset/prompt catalogue inside focused overlays. Improve the design to more closely match bryangarage.dev/showcase.
